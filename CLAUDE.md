# Pirole - Сайт лофт мебели

## О проекте

Лендинг для **Pirole** — мастерской по производству кастомной мебели в индустриальном и лофт стиле для баров, ресторанов и других заведений.

Сайт: https://pirole.ru

## Технологии

- **Nuxt 4.2** (SSG - статическая генерация)
- **Vue 3.5**
- **TypeScript**

## Структура проекта

```
app/
  app.vue          # Главный компонент (весь сайт в одном файле)
public/
  images/          # Изображения галереи и логотип
nuxt.config.ts     # Конфигурация Nuxt, SEO, метаданные
```

## Команды

```bash
npm run dev       # Запуск dev-сервера (localhost:3000)
npm run build     # Сборка для продакшена
npm run generate  # Генерация статического сайта
npm run preview   # Предпросмотр собранного сайта
```

## Секции сайта

1. **Header** - навигация с мобильным меню
2. **Hero** - главный баннер с фоновым изображением
3. **О нас** - описание компании
4. **Галерея** - проекты с лайтбоксом (свайп на мобильных)
5. **Контакты** - телефон: +7 (916) 867-35-50
6. **Footer**

## SEO

- Настроены мета-теги (Open Graph, Twitter Card)
- Schema.org разметка (LocalBusiness, Product)
- Подключены @nuxtjs/robots и @nuxtjs/sitemap

## Стилизация

- CSS-переменные в `:root` для цветовой схемы
- Тёмная тема (--color-bg: #1a1a1a)
- Акцентный цвет: золотой (--color-primary: #c9a227)
- Шрифты: Oswald (заголовки), Open Sans (текст)
- Адаптивность: 1024px, 900px, 600px, 380px брейкпоинты
